Kus kódu (validace zápisu)

// zápis hotové operace — server-side validace
export async function zapisOperaci(vstup: unknown) {
  const op = schemaOperace.parse(vstup);   // tvar dat
  if (!maPravo(op.uzivatel, op.zakazka))    // přístupy
    throw new Chyba('bez oprávnění');
  await db.insert('operace', {
    ...op, cas: Date.now(), zdroj: 'terminal'
  });
  return { ok: true };
}

Fakta

  • Provoz: ~0 Kč/měs (Cloudflare Free).
  • Co je živé: fronta, odpis, docházka a přepočet přehledu — nad demo daty v prohlížeči.
  • Co je ilustrační: čísla zakázek, názvy materiálu, jména.
  • Ostrá verze: sdílená evidence + přístupy + export; data zůstávají tvoje.

Rozpad scénáře

Co bych řešil a co je v ceně

Zadání

Malá výroba/dílna chce evidovat zakázky, materiál a docházku bez těžkého ERP a bez měsíčních licencí.

Problém

Papír + Excel + hlava. Informace se ztrácejí, ručně se přepisuje a vedení nemá přehled v reálném čase.

Řešení

Jednoúčelový terminál: na dílně mobilně zadáš, vedení vidí online. Rychlé, bez balastu, na míru procesu.

Stack

Astro + čistý TypeScript + Cloudflare Worker + D1 (nebo napojení na Google Sheets). Bez pluginů, nulový paušál.

Co je v ceně

Nasazení, napojení, zaškolení, stručný manuál a předání do tvého plného vlastnictví (žádný lock-in).

Co doplníš ty

Seznam operací a materiálu, kdo co dělá a jednoduchá pravidla provozu.

Limity: tohle není plné ERP, mzdy ani účetnictví — je to jednoúčelová evidence + přehled. Na složité integrace na rovinu řeknu, kdy to dává smysl řešit jinak.
