# Ukázky / dema RadeQ — syntéza 3 nezávislých modelů (Opus + GPT + Gemini)

## Shoda všech tří (vysoká důvěra)
- **2 kontrastní persony:** (A) okamžitá akce / lokální SEO / telefon — řemeslník v terénu;
  (B) důvěra / vztah / vizuál — služba (rezervace) nebo portfolio. 2/3 vybraly pro A
  instalatéra.
- **E-shop = pražírna kávy**, malý katalog, drawer košík, bleskový filtr, BEZ účtů a reálné
  platby (demo). VŠICHNI tři ho označili jako kandidáta na ODLOŽENÍ (časová past; malý
  živnostník stejně půjde na Shoptet).
- **Chatbot = lehký „průvodce"** (ne „AI asistent"): jen služby/ceník/postup, Cloudflare
  Workers AI, omezený system promptem, rychlá tlačítka, vínové minimal UI, bezpečné hranice.
- **Blog = „Zápisky"** ANO, ale evergreen (Gemini: bez dat u článků), 3–5 cornerstone,
  žádná kadence; SEO long-tail + krmí chatbota + důvěra.
- **ukázka→reference:** NEnazývat „Reference"; poctivý perex; štítky `VZOROVÝ PROJEKT`
  vs `KLIENTSKÁ REALIZACE`; vzorové weby zůstanou navždy jako „startovní šablony".
- **Nejvyšší prodejní efekt:** 2 persony + chatbot. Vypustit/odložit: e-shop, žádné 3D /
  falešné dashboardy / přebujelé AI.

## Syntetizovaný plán (levnější cenová hladina; složitost cenu zvyšuje — uvést v detailu)
**Ukázka A — Řemeslník v terénu (instalatér/topenář)** · one-pager · H1 „Rychlý instalatér
pro [město] a okolí" · velké `Zavolat` + `Popsat problém` · služby, působnost+mapa,
orientační ceník, FAQ, sticky tel. na mobilu · předvádí lokální SEO + 100/100 výkon ·
světlý, funkční, vínová jen na CTA · **od ~9 900 Kč**.

**Ukázka B — Služba s důvěrou (rezervace)** · multi-page · např. fyzioterapeut/kadeřnice/
poradce · H1 výsledkový · `Najít termín`/`Rezervovat` · Jak pracuji, Služby, FAQ, Rezervace ·
předvádí rezervační tok + formulář přes CF Worker s auto-odpovědí + mapa · teplý, pečlivá
typografie, vínová decentně · **od ~12 900 Kč**. (Alternativa B = portfolio řemeslo
truhlář/čalounictví s galerií před/po — jiná mechanika, stejná „důvěra".)

**E-shop — pražírna kávy (lehká ukázka, NIŽŠÍ priorita / po A+B)** · grid + filtr (View
Transitions), detail s variantou, drawer košík, u pokladny hláška „ukázkový e-shop" ·
mikrointerakce (spinner→fajfka) · **od ~19 900 Kč** (velký e-shop výrazně výš → detail).

**Chatbot — „RadeQ průvodce"** · Workers AI, kontext = vlastní obsah/ceník v promptu,
rychlá tlačítka, „na ostatní se zeptejte Radka", vínová hlavička · **od ~6 900 Kč** jako
služba.

**Zápisky** · 3–5 evergreen článků (bez dat) · témata: „Proč řemeslník nepotřebuje web za
100 tisíc", „Kolik stojí web pro živnostníka a co má být v ceně", „Jak se o web starám po
předání" · úzký sloupec, velké vínové nadpisy.

**Sekce „Práce & koncepty"** · jednotná karta (typ, pro koho, problém, co předvádí, cena
od, CTA) + štítky vzorový/realizace + detail „Co by se změnilo u reálného klienta".

## MVP pořadí (co uveze jeden člověk)
Homepage (Racionální digitalizace + ceník „od" + Servisní protokol/Testerova záruka) →
Ukázka A → Ukázka B → Zápisky (2–3) → chatbot. **E-shop až potom.**
